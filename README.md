Contains data, plots, and code for analysis of recapture data from DSM experimental release.
If entire contents are copied, including file structure herein, code should work and the main script files should open.
Main scripts are as follows: 
a) DistributionMaps (release site map and annual recapture maps)
b) DistancePlots (distance traveled from release site and dispersal from conspecifics)
c) Turbidity (turbidity and first flush)
